# 具身智能产业链

网页：https://huyicheng.github.io/humanoid-robot-chain/

以人形机器人（含四足、轮式人形）为主的具身智能产业链梳理，分成 16 大块、168 块，每一块从整机往上游拆到原料。每块里做这块产品的公司都收进来：A 股、港股、美股、其他交易所，还有没上市的。

网页上有：
- 结论；
- 分布地球仪：每家公司的总部在哪个城市，可按大块、块、档位、上市地筛选；
- 产业链分块：分成哪些块，每块有多少家在做；
- 成本构成：一台机器人的钱花在哪几块；
- 市场份额：每一块谁领先；
- 利润：谁赚钱；
- 门槛和垄断：哪些公司门槛高、利润高、有垄断性；
- 资料缺口：哪些查不到，影响哪些结论；
- 公司名单：可按块、档位、上市地筛选，每行有证据原句和出处；
- 整机厂名单，有开发阶段、资料完整度和官网的机器人页面；
- 资料索引。

几点说明：
- 每家公司的档位按公司自己的年报、公告、招股书、官网或政府文件里的原句定。只有展会页或媒体报道的，档位压低。
- 份额多是咨询机构的估计，每个数都写了是谁的估计、哪一年、什么范围。
- 公司所在地是实际经营的总部所在的城市，不是注册地或上市地。
- 不是投资建议。

这是静态网页。`index.html` 打开时只读 `data/core.json`（目录、各块家数、图的数据），别的用到才读：
- 报告一部分一个文件（`report_s1.json` …）；
- 证据一块一个文件（`ev_A01.json` …）；
- 公司页按公司序号分成 64 份（`co_00.json` …），打开一家公司只读一份；
- 公司名单页读不带原句的 `list.json`，展开一行时再读那一块的证据；
- 搜索框第一次输入时读 `companies.json`；
- 分布地球仪读 `geo.json`（城市和公司）和 `land110.json`（陆地轮廓，放大后再读 `land50.json`）。画图的三个小程序先读网站自己的 `lib/`（d3-array 3.2.4、d3-geo 3.1.1、topojson-client 3.1.0，ISC 许可），读不到再读 cdn.jsdelivr.net 上的同一版本。

第一页出来以后，后台把报告各部分先读好，之后在报告里翻页不用再等网络。

网络断一下或卡住时：
- 一个文件 10 秒没收到新数据，就断开重读；断了也自动重读，一共读 3 次；
- 还读不到，就写明原因，并给一个“再试一次”，不用刷新整页；
- `index.html` 里有每个数据文件的校验值。读到的文件和它对不上，有两种情况：
  - 浏览器缓存里是旧版：绕过缓存重取；
  - 网站刚更新、网页本身是旧版：重新载入一次。
- `#diag` 是连接记录，只存在浏览器里。

`report.json` 是整份报告，网页不读，留给核对脚本用。`fig/` 里是图的静态版。字体用电脑自带的，不从网上下载。最后更新：2026-10-20（第五版）。
